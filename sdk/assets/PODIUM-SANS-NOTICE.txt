Podium Sans — original Apple firmware bitmap font

Source: original iPod Photo firmware 1.2.1.
SHA256: 9321189b846a7317f4f575075696056e9a18c79644886a00055a402259c6fadc
Font header offset: 0x467c94; Unicode group header: 0x46783c.
Strike: 16; bitmap height: 17; bit depth: 4.

font-podium-sans16.json contains printable ASCII 32–126, with original
advances and bitmap samples expanded from 4-bit to 8-bit alpha. A common
one-pixel origin accommodates negative left bearings. No glyphs are resized.
Resource fields were inspected using iPodWizard's Font.h and Font.cpp:
https://github.com/DavidBuchanan314/iPodWizard-mirror

The glyphs retain Apple's ownership. No redistribution license was supplied
with this firmware. This asset is not covered by the DejaVu font license or
by Linnet's source-code license.
